# workasia-media

Imagini **publice** pentru postările sociale WorkAsia.ro.

Buffer nu poate încărca fișiere prin API: preia imaginile doar de la un URL public,
la momentul publicării. De aceea vizualurile aprobate stau aici, ca linkuri
`raw.githubusercontent.com` stabile.

- Un folder per săptămână: `social/AAAA-Wxx/`.
- **Doar vizualuri aprobate la Poarta 4.** Fără cod, fără `.env`, fără drafturi.
- Nu se șterge nimic dintr-o săptămână cu postări încă programate în Buffer —
  postarea ar ieși fără imagine.

Sursa (cod, copy, plan) e în repo-ul privat `vladminerva/workasia`.
